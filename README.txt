# Among Us multiplayer – úlohy

Táto verzia pridáva menu **Úlohy** pred spustením hry.

Hostiteľ:
1. klikne na Vytvoriť,
2. zadá meno,
3. pridáva úlohy,
4. pri každej úlohe musí vyplniť **Miesto** a **Úlohu**,
5. môže úlohy odstraňovať,
6. až potom môže spustiť hru.

V lobby sa úlohy zobrazujú všetkým hráčom. Po spustení dostane Crewmate zoznam
úloh s miestami. Impostor ich nemá.

Spustenie:
npm install
npm start

Potom otvor http://localhost:3000

GitHub Pages samotný nepodporuje Node.js/WebSocket server. Pre internetový
multiplayer treba nasadiť server na hosting, ktorý podporuje Node.js.
