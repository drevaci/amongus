Among Us multiplayer

Spustenie lokalne:
1. npm install
2. npm start
3. otvor http://localhost:3000

Nasadenie na Render:
Build Command: npm install
Start Command: npm start

Server podporuje WebSocket a je nastaveny na PORT a 0.0.0.0.

Zmena: tlačidlo KILL už neumožňuje vybrať cieľ ani nikoho automaticky neoznačí za mŕtveho. Stlačenie KILL iba spustí 30-sekundový cooldown. Kto je v hre zabitý, označí hostiteľ cez hostiteľské rozhranie podľa pravidiel hry.
